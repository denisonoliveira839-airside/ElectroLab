# ElectroLab — Streamlit

## Rodar localmente

```bash
pip install -r requirements.txt
streamlit run app.py
```

Depois abra o endereço mostrado pelo Streamlit.

## Publicar
O projeto foi preparado para o Streamlit Community Cloud:

- `requirements.txt`
