# ElectroLab V2
Bancada elétrica virtual em Streamlit.

Inclui bancada gráfica, componentes residenciais/industriais, arrastar componentes, ligação entre bornes, simulação didática, multímetro, edição de componentes, diagnóstico e salvar/abrir JSON.

Rodar:
pip install -r requirements.txt
streamlit run app.py

A simulação é didática e não substitui projeto, comissionamento ou ensaio elétrico real.
